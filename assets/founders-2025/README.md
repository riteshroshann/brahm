# Founders' Day 2025 photographs

The ten photographs from Founders' Day 2025, re-encoded to 1400px wide, JPEG
q82, progressive. These are the only copies — the original WhatsApp files were
removed once everything here was in place.

"Wardrobe" is **More → Amrita's Wardrobe**, which lists them in the order set
by `WARDROBE_PHOTOS` near the top of the script block in `index.html` (and in
`Brahm 2026 Fest App.dc.html`). The home-screen mosaic is the `.spirit-mosaic`
block in the same file — swap a filename there to feature a different one.

Each path is checked with a `HEAD` request before it renders, so removing a
file here drops it from the page rather than leaving a broken frame.
